# Case Study 07 — 3M

**Organization:** 3M · **Industry:** Diversified manufacturing · **Scale:** Global, many business units

## The challenge
Many teams provisioning Azure resources in inconsistent ways, causing drift, security
gaps, and wasted spend.

## The Terraform-on-Azure pattern (what this repo teaches)
- **Standardized modules** so every workload uses approved patterns.
- **State stored remotely** with locking to avoid concurrent destructive changes.
- CI checks that run `terraform fmt`, `validate`, and `plan` on every change.
- Periodic **drift detection** by re-running `plan` against existing state.

## Outcomes this pattern typically delivers (illustrative)
- Less configuration drift across teams.
- Consistent, approved infrastructure patterns.
- Faster, safer changes through pipelines.
